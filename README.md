# Compoundly

Simulador De Interes Compuesto Moderno, Intuitivo Y Open Source.

## Descripcion

Compoundly Es Una Aplicacion Web Desarrollada Con Next.js Y React Que Permite Simular El Crecimiento De Inversiones A Lo Largo Del Tiempo Utilizando Interes Compuesto.

Esta Diseñada Para Que Cualquier Persona Pueda Entender Facilmente Como Crece Su Dinero Invirtiendo De Forma Constante.

## Caracteristicas

- Calculo De Interes Compuesto En Tiempo Real  
- Aportes Mensuales Configurables  
- Tasa De Retorno Personalizable  
- Simulacion Por Cantidad De Años  
- Calculo De Tiempo Para Alcanzar Un Objetivo (Ej: 1 Millon)  
- Escenarios Predefinidos (Ej: S&P 500)  
- Interfaz Moderna Y Centrada En El Diseño  

## Como Funciona

1. Ingresas Tu Capital Inicial  
2. Definis Tu Aporte Mensual  
3. Elegis Una Tasa De Retorno  
4. Seleccionas El Tiempo  
5. Ves El Resultado De Tu Inversion  

Tambien Podes Definir Un Objetivo Y La App Calcula Cuantos Años Necesitas Para Alcanzarlo.
